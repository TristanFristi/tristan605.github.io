Galerij beheren

Voeg foto's toe aan de galerij op de website, of haal ze weg. Alleen de beheerder met een geldig toegangstoken kan dit.

Inloggen

Hoe maak ik zo'n token aan?
  1. Log in op github.com met het account dat eigenaar is van deze website.
  2. Ga naar Settings → Developer settings → Personal access tokens → Fine-grained tokens en kies Generate new token.
  3. Geef het een naam (bijv. Galerij) en kies een vervaldatum.
  4. Kies bij Repository access → Only select repositories en selecteer tristan605.github.io.
  5. Zet bij Permissions → Repository permissions de optie Contents op Read and write.
  6. Klik op Generate token, kopieer de code (begint met github_pat_) en plak hem hierboven.

Deel het token met niemand. Wordt het gelekt? Verwijder het dan bij GitHub; het werkt meteen niet meer.
